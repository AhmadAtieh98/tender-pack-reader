B. `tenderpack/ai/tools.py` — narrow, read-only tools over the existing modules, each with a name, JSON input schema and JSON-serialisable output, usable in-process, via CLI and via MCP; the tool layer never executes model text, never writes outside `staging/`, and refuses paths outside the pack/evidence build:
- `search_evidence(query, docs=None, kinds=None, limit=20)`: deterministic token-overlap ranking over units (normalised Latin; Arabic preserved), returning unit ids, doc, pages, kind, snippet; no embeddings.
- `get_unit(unit_id, stage=None)`: text as issued and effective text at the stage (engine state), cells, pages, anchors, status, history (op ids), annotations, and for image readings the Arabic source text, the translation and the match text as separate fields (from the units/readings).
- `get_group(group_id, stage=None)`: members of a table/form/list with cells, the heading, notes.
- `get_crop(unit_id)`: path and sha256 of the native crop image (from the build's regions) so a vision-capable provider can attach it; refuse if none.
- `compare_state(from_stage, to_stage)`: the deterministic diff (`live.diff`) plus per-unit changes.
- `calculate(kind, args)`: only approved calculations: date rules via `dates.py` (relative periods, both day-counting readings, working days between), nothing else (no arithmetic from free text).
- `simulate_amendment(addendum, ops, dispositions)`: engine dry run (`amend.Engine` over copies; nothing persisted) returning per-op validity with the check records, coverage, unevidenced additions (C47), scope leak, changed units, and the C46 "needs" (rows required) via `trace`.
- `simulate_programme(stage)`: `programme.plan` read-only on the current rows → milestones and infeasible chains (bounded output).
- `validate_proposal(proposal)`: see C.
- `request_review(proposal_set)`: writes `staging/ai/<run_id>/proposals.yaml` + `review_request.md` + `log.jsonl`; never `curation/`.

C. `tenderpack/ai/controller.py` — the orchestration, deterministic policy: `propose(addendum, route, cfg, …) -> ProposalSet`. Builds the task packet: the state identity (refuse if E01 fails), every provision unit of the addendum (ids, pages, kind, text, candidate targets from `citations`), the pattern draft (as a reference marked "pattern drafter output, unverified"), the required output ("every provision accounted for by an op, a disposition or an escalation; cite exact words; say 'insufficient evidence' rather than complete a plausible answer"), the contract schema and the tool list. Runs provider turns with tool calls, bounded by max_turns/max_calls/max_tokens/max_usd/timeout; parses the final structured output into the contract strictly (malformed → recorded, one retry with the parse error quoted, then status `malformed`); VALIDATES each item and ASSIGNS `verification_status` (the model's value is ignored): `evidence_verified` only if every EvidenceRef's words are verbatim in the named unit's text or cell at the stated state (`register.found`, Arabic via the normalisers in `textnorm`), the page matches, and the state identity equals the current build; amendment_op items additionally require `simulate_amendment` valid (C21–C27, C47) and no conflict; `insufficient_evidence` when a ref fails or none is given; `conflicting` when the op/row has a latest rejection decision, contradicts an accepted decision, or changes a unit the owner's approvals cover (approvals.yaml region ids); `invalid` when the engine refuses; `escalated` for escalations (unsupported structures never become ops); `interpretation_pending` when the item depends on an `interpretation` statement — a verbatim quotation or a well-formed JSON never verifies an interpretation. Computes IMPACT deterministically for the evidence_verified ops (engine dry run vs the current validated state: changed units, rows citing them (→ would be STALE), C46 rows needed, clarification entries citing changed units), records coverage, writes staging, logs every prompt, tool call (+ truncated result), raw response, usage, error and validation to `worklog/model_calls/<run_id>.jsonl` and `staging/ai/<run_id>/log.jsonl` with secrets redacted. Retains the last validated state: nothing it does changes `curation/`, `build/`, `out/`.
