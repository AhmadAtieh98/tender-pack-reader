run only in a Linux cloud container ("cloud-tested" below), which proves nothing about your Mac. Nothing here approves,
accepts or sends anything, and nothing downloads a model. Details: `docs/VERIFY_ON_MAC.md` §5, `docs/MAC_SETUP.md`.
