# CANDIDATE: proposed by the AI workflow; not reviewed; nothing accepted

Every file in this folder was produced by the AI workflow in a disposable candidate workspace. Nothing here is reviewed, accepted or published; the real curation/, config/ and out/ were not changed.

A1's first column after the id gives each row's candidate status:

- **PROPOSED BY THE AI WORKFLOW** (14 rows): a new row or a reading re-made at ADD-03 by this run, validated by the controller; a person decides it (accept / reject)
- **UNRESOLVED** (3 rows): STALE at ADD-03 with no re-made reading, or (value in question) citing a unit an unresolved provision of ADD-03 names: the value shown may be superseded by that provision, which is named with its reason (never 'not changed by this run')
- **DECIDED** (0 rows): a named person's decision in the copied decisions file (none means nobody has decided yet)
- **proposed (existing row)** (196 rows): an existing row this run did not change; not reviewed

Data files that cannot carry a banner (JSON lists) are covered by this file.
